# 常用的文件系统

## BusyBox

> Reference: https://zhuanlan.zhihu.com/p/637951209

### 移植过程

下载源码

在交叉编译环境(UBUNTU 虚拟机, wsl, etc)下的创建根文件系统目录, 名称设置为rootfs

```bash	
mkdir rootfs
# download the source code of busybox
# ...
tar -jxvf busybox-1.32.0.tar.bz2	# 看自己的版本
# modify the ARCH, CROSS_COMPILE in the root Makefile.
ARCH ?= arm
CROSS_COMPILE ?= arm-linux-gnueabihf-
# ...
# add the support for the chinese char.

```
