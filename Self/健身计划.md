## 每周训练安排(每天1小时,但别每天都高强度)

> 力量训练会让肌肉在**休息时**生长,零基础恢复慢。所以把「每天能练」安排成 **4天力量 + 2天恢复 + 1天休息**,每天都有事做,又给肌肉生长时间。

| 星期 | 安排 | 内容 |
|---|---|---|
| 周一 | 上肢力量 | 胸/背/肩/手臂,约50分钟 |
| 周二 | 下肢力量 | 腿/臀/核心,约50分钟 |
| 周三 | 主动恢复 | 快走30-40分钟 **或** 爬楼梯20分钟 + 全身拉伸 |
| 周四 | 上肢力量 | 同周一 |
| 周五 | 下肢力量 | 同周二 |
| 周六 | 主动恢复 | 快走/骑行/游泳30-40分钟 |
| 周日 | 完全休息 | 想动就散散步,不练 |

## 具体动作(零基础友好版)

### 上肢日(每个动作做完歇60-90秒)
| 动作 | 组×次 | 要点 |
|---|---|---|
| 俯卧撑(做不动就跪姿) | 3×8-12 | 身体一条直线,下去胸口贴近地面 |
| 哑铃单臂划船 | 3×10-12/侧 | 背部发力,像「拉抽屉」,不是用手臂拉 |
| 坐姿哑铃推举 | 3×10-12 | 推过头顶,核心收紧,别塌腰 |
| 哑铃弯举(二头) | 3×10-12 | 大臂夹紧不动,只动小臂 |
| 哑铃仰卧臂屈伸(三头) | 3×10-12 | 大臂垂直地面,只动前臂 |
| 哑铃侧平举(肩) | 3×12-15 | 重量要轻,抬到与肩平即可 |

### 下肢日
| 动作 | 组×次 | 要点 |
|---|---|---|
| 高脚杯深蹲 | 3×10-15 | 哑铃抱胸前,膝盖和脚尖同方向,蹲到大腿平行地面 |
| 哑铃罗马尼亚硬拉 | 3×10-12 | 背打直,哑铃贴着大腿下放,练大腿后侧 |
| 哑铃臀桥 | 3×12-15 | 顶端顶峰收缩2秒,臀部发力不是腰 |
| 箭步蹲 | 3×10/腿 | 先徒手做稳,再拿哑铃 |
| 站姿提踵 | 3×15-20 | 小腿,上下都要慢 |
| 平板支撑 | 3×30-60秒 | 腰别塌,收紧臀部和腹部 |

### 关键原则
- **重量怎么选**:选一个你做第3组时「最后1-2个很费力但能标准完成」的重量。不够就加重,过头就减。**动作标准 > 重量**。
- **每天力量训练前**花5分钟热身(开合跳、肩环绕、徒手深蹲),结束后拉伸5分钟。
- 肌肉酸痛(尤其第一周)是正常的,不是受伤,照常安排恢复日就行。

## 饮食方案(外卖/便利店也能执行)

### 目标数字(假设体重约75kg)
- **热量**:每天约 **1600-1800 大卡**(制造 300-500 大卡缺口,这是减肚子最快的速度,又不会掉肌肉)
- **蛋白质**:每天 **110-135g**(≈ 体重×1.5~1.8g/kg,减脂保肌的关键)
- **甜品饮料**:全部无糖(奶茶、含糖饮料、果汁 = 减脂最大敌人,直接砍掉)

### 一日三餐外卖模板
| 餐次 | 怎么点 |
|---|---|
| **早餐**(便利店) | 水煮蛋×2~3 + 无糖豆浆/牛奶 + 玉米或全麦三明治(选鸡肉的) |
| **午餐**(外卖) | 主食减半(米饭少一半)+ 主菜选**鸡胸/牛肉/虾/鱼**(不要炸的)+ 多点蔬菜。推荐:轻食沙拉(酱另放)、黄焖鸡(去皮少汁)、麻辣烫(清汤,多菜多肉少丸子) |
| **晚餐** | 蛋白质为主+蔬菜,主食半碗或不吃。便利店可买:即食鸡胸 + 关东煮(萝卜/豆腐/海带)+ 无糖豆浆 |
| **加餐(可选)** | 饿了吃:水煮蛋、无糖酸奶、一小把坚果;蛋白质吃不够时考虑**乳清蛋白粉**(约1勺20g蛋白) |

### 外卖避雷清单 ❌
油炸食品、糖醋/红烧勾芡菜、肥肉、香肠丸子类、含糖奶茶果汁、汤里的油、沙拉酱整包倒。

### 外卖调整口诀
> **备注「少油少盐」→ 主食减半 → 蛋白质吃到饱 → 只喝无糖 → 七八分饱就停。**

## 睡眠:最大短板,必须改

熬夜会直接**升高皮质醇、降低瘦素,导致减脂变慢、肌肉恢复变差**——你在床上躺平的时间,才是肌肉生长的时间。4周减脂期这是你最容易偷走的分数:

1. **目标**:12点前放下手机,睡足 **7小时**
2. **最有效的一招**:固定每天**早上同一时间起床**(比如8点),晚上困意自然就来
3. 睡前1小时不看短视频/游戏,灯光调暗;训练尽量安排在白天,避免睡前2小时内剧烈运动

哪怕只做到「从凌晨2点提前到12点半」,4周下来减脂效果差异都很大。

## 4周渐进计划 + 预期效果

| 周 | 训练重点 | 饮食重点 |
|---|---|---|
| 第1周 | 学会动作,用轻重量,宁轻勿重 | 先戒奶茶饮料 + 蛋白质吃到每天100g+ |
| 第2周 | 每组比上周多做1-2次,或加1组 | 主食减半养成习惯,热量进1600-1800 |
| 第3周 | 尝试加重量(零基础力量涨得快) | 保持,蛋白质冲上120g+ |
| 第4周 | 保持强度,动作质量优先 | 不松懈,拍照对比 |

**4周现实预期(健康速度)**:
- 体重 **-2~4kg**,腰围 **-2~4cm**(肚子明显变软变小)
- 胸、肩、手臂出现**轮廓**,俯卧撑数量、哑铃重量翻倍
- 这期间体重可能有时不降反而升——**肌肉在涨、水分波动**,**每周同一天早上空腹量腰围**,腰围缩小才是真的瘦了

---

## 新手提醒

1. 每周**固定一天早上**量体重+腰围+拍照,别天天称(焦虑且没意义)
2. 减脂期**别极端节食**,低于1400大卡会掉肌肉、反弹
3. 第一周肌肉酸痛是正常的,恢复日就是用来缓冲的
4. 零基础第一个月是「新手福利期」,力量涨得最快,**坚持别断**,这是你进步最快的时刻
