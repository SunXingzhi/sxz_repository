**第 1 周：U-Boot 启动**

- 跟读 `start.S` → `board_init_f` → `board_init_r`，画出函数调用图。
- 修改 U-Boot 环境变量，让系统从 TFTP 加载内核和 DTB。
- 在 U-Boot 中添加一个自定义命令，练习编译与调试。

**第 2 周：内核启动与设备树**

- 从 `head.S` 跟到 `start_kernel`，列出初始化顺序。
- 修改设备树，添加一个 GPIO LED 节点，并在内核启动后用 `ls /proc/device-tree` 验证。
- 手工编写一个“hello world”内核模块，用 `insmod` 加载，体验模块机制。

**第 3 周：驱动模型与字符设备**

- 写一个完整的字符设备驱动，包括设备树绑定和动态设备号分配。
- 分析 `platform_bus_type` 和 `of_device_id` 的匹配过程，用 ftrace 跟踪 `platform_probe`。

**第 4 周：USB 子系统**

- 阅读 `usb-core` 关键路径，写一个简单的 USB 驱动（如 USB 温度传感器，如果没有硬件，可以用 QEMU 模拟）。
- 打印出 `struct usb_device` 各成员，理解描述符、配置、接口、端点。

**第 5 周：蓝牙与音频**

- 分析 `btusb.c` 的 probe 过程，追踪 HCI 包的收发。
- 从用户空间配对蓝牙音箱，抓取 `hcidump` 或使用 `btmon` 观察底层交互。
- 阅读 ALSA USB Audio Class 驱动（`sound/usb/`）的部分源码，理解 USB 音频流如何映射到 PCM 设备。

**第 6 周：综合项目**

- 尝试自己写一个应用程序，使用 BlueZ D-Bus API 自动连接蓝牙音箱并播放一段 WAV 文件。
- 修改内核，在蓝牙音频建立连接时打印自定义信息，添加一个简单的 `/proc` 接口显示当前连接的设备名。
